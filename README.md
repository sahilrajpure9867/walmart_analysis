# 📌 Project Overview

The **Walmart Sales Analysis Dashboard** is an **end-to-end Business Intelligence project** built to analyze retail sales performance, customer purchasing behavior, branch performance, payment preferences, and product profitability.

The project demonstrates a complete analytics workflow from **data cleaning and exploratory data analysis (EDA)** to **SQL business analysis** and **interactive Power BI dashboards**, enabling data-driven business decisions. The analysis addresses retail business questions such as payment methods, branch performance, category ratings, sales shifts, and revenue trends. :contentReference[oaicite:0]{index=0}

# 🚀 How to Run

### Clone Repository

```bash
git clone https://github.com/yourusername/Walmart-Sales-Analysis.git
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Jupyter Notebook

```bash
jupyter notebook
```

### Execute SQL Queries

Run the SQL scripts from the **sql/** folder in MySQL or PostgreSQL.

### Open Power BI Dashboard

```text
Walmart Sales Dashboard.pbix
```
